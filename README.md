# Insurance Claim Fraud Detection System

## Overview
A web-based insurance claim management system developed using PHP and MySQL with fraud detection capabilities. The system helps users submit claims and allows administrators to verify, analyze, and manage claims efficiently.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Python (Machine Learning)

## Features
- User claim submission
- Admin dashboard
- Claim approval/rejection workflow
- Fraud prediction model
- Claim status tracking
- Report generation

## Project Structure
- PHP files: Backend logic
- HTML/CSS/JS: User interface
- Python files: Fraud detection model
- SQL database: Data storage
